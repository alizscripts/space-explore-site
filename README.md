# Space Exploration

An interactive 3D space exploration website built with React, TypeScript, and Three.js.

Explore the Solar System and discover planets through a modern, immersive interface with interactive 3D visuals.

## Tech Stack

* React
* TypeScript
* Three.js
* React Three Fiber
* Vite

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The project will be available locally at the address shown in the terminal.

## Status

This project is actively being developed. New features, improvements, and optimizations will be added over time.
