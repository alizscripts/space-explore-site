
# 🌌 Space Explore

An immersive interactive space exploration website built with React, TypeScript, and Three.js.

Explore the Solar System, discover deep-space objects, and experience a cinematic space-themed interface with interactive 3D planets, animations, and responsive layouts.

## 🚀 Live Demo

[Explore Space Explore](https://alizscripts.github.io/space-explore-site/)

## ✨ Features

- 🪐 Interactive 3D Solar System
- 🌌 Deep-space exploration
- ✨ Animated starfield and mouse interactions
- 🎨 Modern dark space-themed UI
- 📱 Responsive design for desktop and mobile
- ⚡ Smooth page transitions and animations
- 🖼️ Local planetary textures and visual assets

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- Drei
- Motion
- Tailwind CSS
- React Router

## 📂 Project Structure

```text
src/
├── components/    # Reusable UI and visual components
├── pages/         # Main application pages
├── App.tsx        # Application layout and routing
└── main.tsx       # Application entry point

public/
└── textures/      # Planetary textures and visual assets
````

## 💻 Run Locally

```bash
git clone https://github.com/alizscripts/space-explore-site.git
cd space-explore-site
npm install
npm run dev
```

Then open the local development URL shown in your terminal.

## 📌 About

Space Explore is a personal front-end project focused on combining modern web development with interactive 3D graphics and immersive visual design.

Built to explore React, Three.js, WebGL, animation, responsive design, and modern front-end development.
